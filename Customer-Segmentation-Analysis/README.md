# Customer Segmentation Analysis - OIBSIP Task 2

## Objective

To segment customers into different groups based on their Annual Income and Spending Score using the K-Means Clustering algorithm and understand customer purchasing behavior.

## Dataset

The dataset contains customer information with the following columns:

* CustomerID
* Gender
* Age
* Annual Income (k$)
* Spending Score (1–100)

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Analysis Performed

* Loaded and explored the customer dataset.
* Checked the dataset structure and data types.
* Checked for missing values and cleaned the data.
* Performed Exploratory Data Analysis (EDA).
* Selected Annual Income and Spending Score for customer segmentation.
* Standardized the selected features using StandardScaler.
* Used the Elbow Method to determine the optimal number of clusters.
* Applied the K-Means Clustering algorithm.
* Visualized the customer segments.
* Analyzed the characteristics of each customer group.

## Key Insights

* Customers were segmented into **five distinct groups** using K-Means Clustering.
* Some customers have high annual income but relatively low spending scores, representing potential customers for targeted marketing.
* Customers with high income and high spending scores are valuable customer segments.
* Customers with lower income and lower spending scores may require different marketing strategies.
* Customer segmentation helps businesses understand customer behavior and design targeted campaigns.

## Conclusion

The Customer Segmentation Analysis successfully grouped customers into five different segments using the K-Means Clustering algorithm. The analysis provides useful insights into customer behavior based on income and spending patterns.

### Business Recommendations

1. Provide loyalty programs and exclusive offers to high-value customers.
2. Use personalized promotions to encourage low-spending customers to purchase more.
3. Create targeted marketing campaigns for different customer segments.
4. Offer suitable discounts and product bundles based on customer behavior.
