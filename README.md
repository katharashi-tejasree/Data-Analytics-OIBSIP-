# Customer Segmentation Analysis using K-Means Clustering

## Project Overview

This project performs Customer Segmentation Analysis using the K-Means Clustering algorithm. The objective is to group customers into different segments based on their Annual Income and Spending Score. These customer segments help businesses understand customer behavior and create targeted marketing strategies.

## Objective

- Analyze customer purchasing behavior.
- Segment customers using K-Means Clustering.
- Identify different customer groups.
- Provide business insights and marketing recommendations.

##  Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

##  Dataset

The dataset contains customer information with the following features:

- CustomerID 
- Gender
- Age
- Annual Income (k$)
- Spending Score (1–100)
  
##  Project Workflow

1. Load the dataset.
2. Inspect and clean the data.
3. Handle missing values.
4. Perform Exploratory Data Analysis (EDA).
5. Select features for clustering.
6. Standardize the data using Standard Scaler.
7. Use the Elbow Method to determine the optimal number of clusters.
8. Apply K-Means Clustering.
9. Visualize customer clusters.
10. Generate marketing insights and business recommendations.

##  Results

- Customers were segmented into five distinct groups.
- High-income customers with low spending have strong growth potential.
- Personalized marketing strategies can improve customer engagement and increase sales.
- Customer segmentation helps businesses make better marketing decisions.

##  Business Recommendations

- Introduce loyalty programs for valuable customers.
- Offer personalized promotions to increase spending.
- Provide seasonal discounts and product bundles.
- Use targeted marketing campaigns for different customer segments.

## Conclusion

This project successfully segmented customers into five different groups using the K-Means Clustering algorithm. The analysis provides valuable insights into customer purchasing behavior and helps businesses develop effective marketing strategies.
