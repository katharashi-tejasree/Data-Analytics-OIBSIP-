# Retail Sales Analysis - OIBSIP Task 1

## Objective

To perform Exploratory Data Analysis (EDA) on retail sales data using Python and identify useful patterns, trends, and customer purchasing behavior.

## Dataset

The dataset contains retail transaction details with the following columns:

* Transaction ID
* Date
* Customer ID
* Gender
* Age
* Product Category
* Quantity
* Price per Unit
* Total Amount

The dataset contains **1,000 transactions and 9 columns** with no missing values.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Analysis Performed

* Loaded and explored the retail sales dataset.
* Checked dataset structure, data types, and missing values.
* Performed data cleaning and preprocessing.
* Analyzed sales based on product categories.
* Analyzed customer demographics such as age and gender.
* Examined quantity, price per unit, and total amount.
* Created visualizations using Matplotlib and Seaborn.
* Used a boxplot to compare Total Amount across Product Categories.
* Identified important sales patterns and trends.

## Key Insights

* The analysis helps identify differences in sales performance across product categories.
* Customers in the **26–45 age group** represent an important customer segment.
* Product categories show differences in their sales distribution.
* Transaction quantity and total amount can help businesses understand purchasing behavior.
* Sales analysis can support better inventory planning and demand forecasting.

## Conclusion

The Retail Sales Analysis provides useful insights into customer purchasing behavior and product category performance. The findings can help businesses improve inventory management, identify important customer segments, forecast demand, and encourage bulk purchases.

### Business Recommendations

1. Prioritize inventory for high-performing product categories.
2. Target customers in the 26–45 age group with suitable marketing campaigns.
3. Use historical sales patterns for better demand forecasting.
4. Encourage bulk purchases through suitable offers and discounts.
